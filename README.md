## Что я сделала

В этой работе сделала небольшую игру «Тамагочи». Нужно следить за тремя показателями кота Персика: сытостью, счастьем и энергией. Они постепенно уменьшаются. Если один из них станет равен нулю, игра закончится, но питомца можно завести заново.

В игре есть кормление, игра, сон и дрессировка. Дрессировка объединяет несколько действий. Каждое действие занимает время, поэтому использовала `Promise`, `.then()`, `.catch()` и `.finally()`. `async/await` не использовала.

Добавила очередь: одно действие выполняется, ещё три могут ожидать. Периодически питомец может убежать — на его поимку даётся 3 секунды. Если не успеть, уменьшается счастье.

Для оформления нарисовала кота с помощью SVG и добавила простые CSS-анимации. Внизу страницы есть скрытая панель с настройками: можно менять скорость игры, изменение показателей, вероятность блуждания и начинать игру заново.

## Как запустить на MacBook

Если проект ещё не скачан, откройте Терминал и выполните:

```bash
git clone https://github.com/alinakashafutdinova/client-side-basics.git
cd client-side-basics
git switch lab4
```

Если проект уже есть на компьютере, вместо повторного скачивания перейдите в его папку и выполните `git fetch origin` и `git switch lab4`.

Затем запустите локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
```

Откройте в браузере `http://localhost:8000`. Чтобы остановить сервер, нажмите `Ctrl + C` в Терминале.

## Проверка ESLint

Если установлен Node.js с npm, выполните на MacBook или Windows:

```bash
npm install
npm run lint
```

При успешной проверке ESLint не должен выводить ошибок.

## Как проверить игру

1. Нажмите «Покормить» и посмотрите, как постепенно растёт сытость.
2. Попробуйте нажать несколько кнопок подряд. Пока идёт первое действие, следующие попадут в очередь. Больше трёх ожидающих действий добавить нельзя.
3. Проверьте игру, сон и дрессировку. Дрессировка запускает кормление и игру одновременно, а также восстанавливает энергию.
4. Попробуйте покормить полностью сытого питомца. Появится сообщение об отказе, а питомец встряхнётся.
5. Откройте «Настройки для проверки работы» и нажмите «Запустить блуждание». Попробуйте поймать питомца до завершения отсчёта, а затем повторите и дождитесь конца времени.
6. В настройках можно ускорить снижение показателей, чтобы проверить завершение игры и кнопку «Начать заново».
7. Проверьте игру на узком экране и посмотрите, нет ли ошибок в консоли браузера.

При обновлении страницы игра начинается заново. Это учебный проект, сохранение прогресса не требуется.
