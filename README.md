# Лабораторная работа №1. JavaScript: синтаксис

**Дисциплина:** Основы веб-разработки на стороне клиента  
**Студентка:** Кашафутдинова Алина Тимуровна  
**Группа:** 257-321

## Цель работы

Изучить базовый синтаксис JavaScript и применить его на практике: использовать переменные, условия, циклы, функции, массивы, объекты и методы `Math`. Научиться запускать JavaScript на веб-странице и проверять результаты через консоль браузера.

## Выполненные задачи

1. **Треугольник** — проверка существования, расчёт периметра, площади по формуле Герона и соотношения периметра к площади.
2. **Fizz-Buzz** — перебор чисел от 0 с выводом buzz, fizz и fizz buzz.
3. **Ёлка** — строка из чередующихся * и # с заданной высотой и стволом.
4. **Деление** — проверка делимости числа одновременно на два числа.
5. **Сэндвичи с сыром** — максимальное количество сэндвичей по запасам хлеба и сыра.
6. **Абсолютное значение** — модуль числа без метода Math.abs().
7. **Конвертация температуры** — преобразование температур между шкалами Цельсия и Фаренгейта.
8. **Случайные числа** — получение целого числа в диапазоне включительно.
9. **Значения из массива** — случайный выбор элементов с возможными повторениями.
10. **Фильтрация массива** — аналог filter с передаваемой функцией-предикатом.
11. **Равенство дробных чисел** — приближённое сравнение с Number.EPSILON.

## Структура

- `index.html` — страница с ФИО, группой и перечнем заданий.
- `style.css` — оформление страницы.
- `script.js` — решения всех 11 задач и проверочные примеры.
- `README.md` — описание лабораторной работы и инструкции.

## Запуск

1. Скачать проект или клонировать репозиторий и перейти в ветку `lab1`.
2. Открыть `index.html` в браузере.
3. Открыть консоль браузера: на Mac в Chrome нажать `⌥ Option + ⌘ Command + J`.
4. Просмотреть результаты всех заданий: проверочные примеры выполняются при загрузке страницы.

Для дополнительной проверки можно вызвать в консоли:

```js
printTriangle(5, 5, 6);
fizzBuzz(15);
console.log(makeTree(5));
console.log(countSandwiches({ bread: 8, cheese: 3 }));
console.log(convertTemperature(100, 'toC'));
console.log(toBeCloseTo(0.1 + 0.2, 0.3));
```

## Замечания

- Ноль в Fizz-Buzz выводится как buzz, в соответствии с примером в задании.
- При выборе значений из массива возможны повторения, как в образце.
- Для случайных чисел обе границы диапазона включены.
- В вычислении треугольника применяется формула Герона.
- При выводе результатов округляются только отображаемые значения.
