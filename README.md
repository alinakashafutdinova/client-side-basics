## Что я сделала

В этой работе потренировалась писать функции, условия и циклы на JavaScript. Всего сделала 11 заданий: треугольник, Fizz-Buzz, ёлка, деление, сэндвичи, модуль числа, перевод температуры, случайные числа, выбор и фильтрация элементов массива, сравнение дробных чисел.

Код всех заданий находится в `script.js`. В `index.html` сделала страницу с именем и списком заданий, а в `style.css` — оформление. Результаты выводятся в консоль браузера.

## Как запустить на MacBook

1. Скачать проект и открыть папку с лабораторной.
2. Если работа скачивается через Git, выполнить:

```bash
git clone https://github.com/alinakashafutdinova/client-side-basics.git
cd client-side-basics
git switch lab1
```

3. Для запуска через локальный сервер открыть Терминал в папке проекта и ввести:

```bash
python3 -m http.server 8000
```

4. Открыть в браузере `http://localhost:8000`.
5. В Chrome или Яндекс Браузере открыть консоль сочетанием `⌘ Command + ⌥ Option + J`.

## Как запустить на Windows

1. Скачать проект (или клонировать его через Git и перейти на ветку `lab1`).
2. Открыть PowerShell в папке с файлами.
3. Если установлен Python, выполнить:

```powershell
py -m http.server 8000
```

4. Открыть `http://localhost:8000` в браузере.
5. Открыть консоль сочетанием `Ctrl + Shift + J`.

Если Python не установлен, можно просто открыть `index.html` двойным щелчком. Но локальный сервер удобнее: при открытии через `file://` браузер иногда показывает предупреждения безопасности, не связанные с заданиями.
