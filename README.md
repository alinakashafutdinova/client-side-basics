## Что я сделала

В этой работе научилась находить элементы страницы через JavaScript и менять их после действий пользователя.

На странице есть пять заданий:

1. Кнопка «Нравится», которую можно включать и выключать.
2. Лайк и дизлайк — одновременно выбрать обе реакции нельзя.
3. Три товара и корзина со счётчиком.
4. Сортировка чисел по возрастанию, убыванию и в исходном порядке.
5. Галерея из 10 фотографий. Можно зажать фото на секунду, выбрать остальные, а потом перенести или удалить выбранные.

Разметка находится в `index.html`, оформление — в `style.css`, вся работа с кнопками и фотографиями — в `script.js`.

## Запуск на MacBook

Если вы ещё не скачали проект:

```bash
git clone https://github.com/alinakashafutdinova/client-side-basics.git
cd client-side-basics
git switch lab2
```

Откройте Терминал в папке проекта и выполните:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000` в браузере.

## Запуск на Windows

Скачайте проект и откройте PowerShell в папке лабораторной. Если у вас установлен Python, выполните:

```powershell
py -m http.server 8000
```

Откройте `http://localhost:8000`. Если скачивали проект через Git, перед запуском перейдите в ветку `lab2`.

Вы также можете открыть сайт двойным щелчком по `index.html`, но через локальный сервер удобнее. Для фотографий нужен интернет.

## Проверка ESLint

Для этого нужен установленный [Node.js](https://nodejs.org/) с npm. На MacBook и Windows команды одинаковые:

```bash
npm install
npm run lint
```

Если ошибок нет, команда заканчивает работу без списка замечаний.

## Как проверить задания

- Нажмите «Нравится» дважды — отметка должна сняться.
- Переключите лайк и дизлайк — активной останется только одна реакция.
- Добавьте товар несколько раз — счётчик корзины увеличится.
- Нажмите все три кнопки сортировки и восстановите исходный порядок.
- Удерживайте фотографию 1 секунду, выберите ещё несколько и проверьте перенос и удаление. Для выбора с клавиатуры используйте `Shift + Enter`.
- Откройте консоль браузера и проверьте, нет ли ошибок (MacBook: `⌘ + ⌥ + J`, Windows: `Ctrl + Shift + J`).

После обновления страницы состояние заданий сбрасывается. Для этой работы сохранять его не требуется.
