## Что я сделала

В этой работе сравнила несколько способов добавления и удаления HTML-элементов. Для этого сделала страницу, которая сама запускает тесты, измеряет время через `performance.now()` и показывает результаты в таблице и на небольших диаграммах.

Для **добавления** использовала `appendChild`, `DocumentFragment`, `innerHTML` и `insertAdjacentHTML`. Для **удаления** — `removeChild`, `innerHTML = ''`, `replaceChildren` и `Range.deleteContents`.

Каждый способ проверяется на **1 000 и 10 000 элементов**. Сначала выполняются 5 пробных запусков, затем **30 измерений**, которые идут в расчёт. Между сериями сделаны небольшие паузы. После завершения можно скачать CSV, JSON с отдельными замерами и отчёт в Markdown.

В статистике считаются среднее время, выборочное стандартное отклонение и доверительный интервал 95%. Чтобы проверить результат, программа также следит за правильным количеством элементов после каждой операции.

## Файлы

- `index.html` — сама страница.
- `style.css` — оформление для компьютера и телефона.
- `src/methods.js` — способы добавления и удаления элементов.
- `src/benchmark.js` — автоматические замеры времени.
- `src/stats.js` — статистические расчёты.
- `src/report.js` — подготовка таблиц и текста отчёта.
- `src/app.js` — кнопки, таблица и диаграммы.
- `REPORT.md` — отчёт с результатами моего пробного запуска в Chromium.
- `data/` — исходные замеры из того же запуска (JSON и CSV).
- `tests/` — небольшие тесты, проверяющие расчёты.

## Запуск на MacBook

Если проект ещё не скачан, откройте Терминал и выполните:

```bash
git clone https://github.com/alinakashafutdinova/client-side-basics.git
cd client-side-basics
git switch lab7
```

Если папка репозитория уже есть, откройте её и вместо клонирования выполните `git fetch origin` и `git switch lab7`.

Запустите локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
```

Затем откройте в браузере `http://localhost:8000`.

## Запуск на Windows

Скачайте проект или клонируйте репозиторий и перейдите в ветку `lab7`. Откройте PowerShell в папке лабораторной и введите:

```powershell
py -m http.server 8000
```

Откройте `http://localhost:8000` в браузере. Если Python не установлен, можно использовать Live Server в VS Code.

## Как провести эксперимент

1. Откройте сайт в режиме инкогнито без расширений и закройте лишние вкладки.
2. Нажмите кнопку **«Запустить сравнение»**.
3. Дождитесь завершения всех 16 серий: 8 методов × 2 размера.
4. Просмотрите таблицу, диаграммы и выводы.
5. Если нужны результаты для своего компьютера, скачайте отчёт через кнопку **«Скачать отчёт Markdown»** — он будет содержать новые измерения с вашего устройства.

Цифры в `REPORT.md` сделаны на тестовом компьютере в Chromium, поэтому на другом устройстве время и порядок методов могут отличаться. Здесь важно не получить определённую цифру, а правильно провести эксперимент и объяснить результат.
