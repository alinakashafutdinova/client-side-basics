## Что я сделала

В этой работе научилась находить элементы страницы через JavaScript и менять их после действий пользователя.

На странице есть пять заданий:

1. Кнопка «Нравится», которую можно включать и выключать.
2. Лайк и дизлайк — одновременно выбрать обе реакции нельзя.
3. Три товара и корзина со счётчиком.
4. Сортировка чисел по возрастанию, убыванию и в исходном порядке.
5. Галерея из 10 фотографий. Можно зажать фото на секунду, выбрать остальные, а потом перенести или удалить выбранные.

Разметка находится в `index.html`, оформление — в `style.css`, вся работа с кнопками и фотографиями — в `script.js`.

## Запуск на MacBook

Если проект ещё не скачан:

```bash
git clone https://github.com/alinakashafutdinova/client-side-basics.git
cd client-side-basics
git switch lab2
```

В Терминале из папки проекта:

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000` в браузере.

## Запуск на Windows

Скачать проект и открыть PowerShell в папке лабораторной. Если есть Python:

```powershell
py -m http.server 8000
```

Открыть `http://localhost:8000`. Если скачивали через Git, перед запуском нужно выбрать ветку `lab2`.

Сайт можно открыть и двойным щелчком по `index.html`, но через локальный сервер удобнее. Для фотографий нужен интернет.

## Проверка ESLint

Для этого нужен установленный [Node.js](https://nodejs.org/) с npm. На MacBook и Windows команды одинаковые:

```bash
npm install
npm run lint
```

Если ошибок нет, команда заканчивает работу без списка замечаний.

## Как проверить задания

- Дважды нажать «Нравится» — отметка должна сняться.
- Переключить лайк и дизлайк — активной остаётся только одна реакция.
- Несколько раз добавить товар — счётчик корзины увеличится.
- Нажать все три кнопки сортировки и вернуть исходный порядок.
- Зажать фотографию на 1 секунду, выбрать ещё несколько и проверить перенос и удаление. Для выбора с клавиатуры можно использовать `Shift + Enter`.
- Открыть консоль браузера и проверить, нет ли ошибок (MacBook: `⌘ + ⌥ + J`, Windows: `Ctrl + Shift + J`).

После обновления страницы состояние заданий сбрасывается. Для этой работы сохранять его не требуется.
