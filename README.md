## Что я сделала

Сделала небольшую страницу с кнопкой «Регистрация». При нажатии открывается окно с формой. В ней можно ввести имя, почту, телефон, возраст, ссылку на GitHub, дату регистрации и пароль.

Когда выходишь из поля, JavaScript проверяет, правильно ли оно заполнено. Если есть ошибка, появляется подсказка. Например, имя не должно содержать цифры, возраст не может быть больше 99, а ссылку на GitHub нужно указывать вместе с датой регистрации.

После нажатия «Отправить анкету» проверяются все поля. Если всё правильно, окно закрывается, а на странице появляется карточка с введёнными данными. Телефон показывается в формате `+7 (999) 123-4567`. Сам пароль в карточку не вывожу.

Для оформления подключила библиотеку Pico CSS и добавила собственные стили. Для проверки полей использовала Constraint Validation API и события JavaScript.

## Файлы

- `index.html` — страница и форма регистрации.
- `style.css` — оформление страницы и окна.
- `script.js` — проверки полей, кнопки и создание карточки.
- `eslint.config.mjs` и `package.json` — настройки проверки JavaScript.

## Как запустить на MacBook

Если репозиторий ещё не скачан:

```bash
git clone https://github.com/alinakashafutdinova/client-side-basics.git
cd client-side-basics
git switch lab3
```

В папке проекта выполнить:

```bash
python3 -m http.server 8000
```

Открыть в браузере `http://localhost:8000`. Остановить сервер можно сочетанием `Ctrl + C` в Терминале.

## Как запустить на Windows

Скачать проект или клонировать его через Git, затем перейти на ветку `lab3`. Открыть PowerShell в папке проекта и выполнить:

```powershell
py -m http.server 8000
```

Открыть `http://localhost:8000` в браузере. Команда работает, если установлен Python. Если Python нет, можно открыть `index.html` прямо в браузере или использовать Live Server в VS Code.

Для загрузки Pico CSS нужен интернет. Если он недоступен, основные стили в `style.css` всё равно будут работать.

## Как проверить работу формы

1. Открыть регистрацию и нажать «Отправить анкету» с пустыми полями. Должны появиться ошибки у имени и почты, а курсор перейдёт к первому полю.
2. Ввести в имя цифры, неправильную почту, короткий телефон или возраст больше 99. После выхода из поля появится сообщение об ошибке.
3. Попробовать указать только ссылку на GitHub без даты, а потом только дату без ссылки.
4. Ввести пароль короче 6 символов. Зажать кнопку показа пароля — пароль должен отображаться только пока кнопка удерживается.
5. Исправить ошибки и отправить форму. Должна появиться карточка. Проверить формат телефона.
6. Открыть форму ещё раз, закрыть её кнопкой, клавишей `Esc` и нажатием на затемнённый фон.
7. Проверить консоль браузера: на MacBook `⌘ Command + ⌥ Option + J`, на Windows `Ctrl + Shift + J`.

Данные никуда не отправляются и после обновления страницы сбрасываются — это учебная форма.
