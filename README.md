## Что я сделала

В этой работе научилась получать и отправлять данные с помощью `fetch()`. Сделала страницу с двумя основными разделами: галереей изображений и формой для отправки температуры в аудитории.

- **Галерея.** При открытии страницы отправляется GET-запрос, пока ожидается ответ — виден загрузчик. Если сервер недоступен, выполняются ещё три попытки. Изображения находятся в одинаковых карточках по четыре в ряд на компьютере. Есть кнопка обновления. Если сервер вернул пустой массив, появляется надпись «Изображения не найдены».
- **Температура.** В форме можно ввести аудиторию и температуру. При отправке получается JSON, в котором аудитория — строка, а температура — число. После успешного POST-запроса появляется уведомление и форма очищается. При ошибке поля остаются заполненными.
- **Уведомления.** Сообщения показываются внизу справа. Успешные — зелёные, ошибки — красные. Окно закрывается кнопкой.
- **Темы.** Светлую и тёмную тему можно переключать в шапке страницы. Выбор сохраняется в `localStorage` и восстанавливается ещё до загрузки стилей, поэтому при обновлении страницы тема не мигает.

Для лабораторной использовала HTML, CSS и обычный JavaScript без дополнительных библиотек интерфейса.

## Что находится в папке

- `index.html` — страница с галереей, формой, кнопкой темы и уведомлением.
- `style.css` — стили, в том числе для телефона и тёмной темы.
- `script.js` — все запросы через `fetch()`, обработка ответов и ошибок.
- `config.js` — адреса запросов и названия полей для отправки.
- `server.py` — небольшой учебный сервер, чтобы можно было проверить работу без сторонних сервисов.
- `assets/` — изображения для локальной галереи.
- `package.json` и `eslint.config.mjs` — проверка JavaScript с помощью ESLint.

## Как запустить на MacBook

Нужен Python 3. Перейдите в Терминале в папку `lab5_fetch` и выполните:

```bash
python3 server.py
```

Откройте в браузере **http://localhost:8000**. Для остановки сервера используйте `Ctrl + C` в Терминале.

## Как запустить на Windows

Установите Python 3, если он ещё не установлен. Откройте папку `lab5_fetch`, нажмите в адресной строке Проводника, напишите `powershell` и нажмите Enter. Введите:

```powershell
py server.py
```

Затем откройте **http://localhost:8000**. Остановить сервер можно клавишами `Ctrl + C`.

**Важно:** не открывайте `index.html` через `file://`, потому что в этой работе используются запросы к серверу. Просто открыть HTML-файл недостаточно.

## Проверка ESLint

Если установлен Node.js, команды для MacBook и Windows одинаковые. В папке лабораторной выполните:

```bash
npm install
npm run lint
```

Если замечаний нет, проверка закончится без сообщений об ошибках.

При желании можно дополнительно запустить проверки логики JavaScript и локального API:

```bash
npm run test:client
python3 -m unittest discover -s tests -v
```

На Windows во второй команде используйте `py` вместо `python3`.

## Как проверить работу

1. Откройте страницу. В галерее должен появиться загрузчик, а затем — восемь изображений.
2. Нажмите «Обновить галерею». После нового GET-запроса появится зелёное уведомление.
3. Введите, например, аудиторию `310` и температуру `22.5`. Нажмите «Отправить данные». После успешного POST-запроса форма очистится и появится ответ сервера.
4. Переключите тёмную тему, обновите страницу и убедитесь, что выбор сохранился.
5. Откройте инструменты разработчика, вкладку Network («Сеть»). Там можно увидеть GET-запрос к `/api/images` и POST-запрос к `/api/temperature`. У POST-запроса заголовок `Content-Type: application/json`.
6. Проверьте страницу на телефоне или уменьшите окно браузера. Карточки должны перестраиваться.

**Дополнительно для проверки ошибок:** в `config.js` можно временно изменить `galleryUrl` на `/api/images?demo=empty` (пустая галерея) или `/api/images?demo=error` (сервер отвечает ошибкой, после четырёх запросов появляется красное уведомление). После проверки верните `/api/images`.

## Про сервер преподавателя

В задании упоминается сервер с документацией, но в доступном тексте страницы не указан его точный адрес и формат ответа. Поэтому я добавила **локальный учебный сервер** `server.py` — на нём GET и POST работают по-настоящему. Это не сервер преподавателя.

Когда будет известен адрес API преподавателя, его можно указать в `config.js`. Если его JSON-ответ или названия полей отличаются от локального примера, потребуется проверить их по документации и при необходимости изменить `normalizeImages()` и названия полей в `config.js`. До этого момента работу с сервером преподавателя нельзя считать проверенной.
