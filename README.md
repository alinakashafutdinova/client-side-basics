## Что я сделала

В этой работе выполнила четыре задания на JavaScript.

1. **Версии программы.** Написала функцию-конструктор `VersionManager`. Можно увеличивать major, minor и patch и отменять предыдущие изменения.
2. **Фигуры.** Сделала классы `Rectangle` и `Square`. Квадрат наследуется от прямоугольника, а площадь и периметр вычисляются общими методами.
3. **Температура.** Написала класс `Temperature` с переводом в градусы Цельсия, Фаренгейта и Кельвины. Он не принимает значения ниже абсолютного нуля. На странице также есть сложение и вычитание.
4. **Камень, ножницы, бумага.** Сделала трансляцию через `EventSource` (SSE). При поступлении раунда сигналы и эффекты обновляют счёт, историю и статистику игроков.

Для оформления выбрала светлые цвета с розовыми акцентами. Страница адаптируется под телефон. В интерфейсе используются обращения на «вы».

## Из чего состоит проект

- `index.html` — страница с заданиями.
- `style.css` — оформление.
- `js/version-manager.mjs`, `js/geometry.mjs`, `js/temperature.mjs` — первые три задания.
- `js/signals.mjs`, `js/game.mjs`, `js/app.mjs` — сигналы, правила игры и обработчики кнопок.
- `js/config.mjs` — настройки адресов трансляции.
- `server.py` — небольшой сервер, который отправляет учебные события SSE.
- `tests/lab6.test.mjs` — проверки основных функций.

## Как запустить на MacBook

1. Скачайте проект или клонируйте репозиторий и выберите ветку `lab6`.
2. Откройте Терминал в папке с файлами.
3. Запустите сервер:

```bash
python3 server.py
```

4. Откройте `http://localhost:8000` в браузере.
5. В четвёртом задании выберите «Локальная демонстрация» и нажмите «Следить за играми».

Остановка сервера — `Ctrl + C` в Терминале.

## Как запустить на Windows

1. Откройте PowerShell в папке с лабораторной.
2. При установленном Python выполните:

```powershell
py server.py
```

3. Откройте `http://localhost:8000`.
4. Для проверки SSE выберите «Локальная демонстрация».

Просто открывать `index.html` двойным щелчком не стоит: JavaScript использует модули, а для SSE нужен работающий сервер.

## Как проверить

- Создайте версию `1.2.3`, увеличьте minor и нажмите «Откатить».
- Введите стороны `5` и `5`. На странице должен определиться квадрат с площадью `25`.
- Введите `0` °C, выберите Фаренгейты и убедитесь, что получится `32` °F. Попробуйте также значение ниже `−273,15` °C.
- Включите локальную трансляцию. Каждые две секунды будет появляться новый раунд. Проверьте, как меняются счёт, статистика и история.

Для проверки функций без браузера понадобится Node.js:

```bash
npm test
```

Для проверки стиля кода установите зависимости и запустите ESLint:

```bash
npm install
npm run lint
```

## Сервер преподавателя

Для удобства добавила локальную трансляцию. Это **не замена проверке с сервером преподавателя**. Если преподаватель выдаст рабочую ссылку на SSE, её нужно вставить в `js/config.mjs` как значение `TEACHER_SSE_URL`, затем выбрать на странице «Сервер преподавателя». Адрес намеренно оставлен пустым, потому что он не был подтверждён.
