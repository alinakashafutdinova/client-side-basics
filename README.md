## Что я сделала

Сделала небольшую страницу с кнопкой «Регистрация». При нажатии открывается окно с формой. В ней можно ввести имя, почту, телефон, возраст, ссылку на GitHub, дату регистрации и пароль.

Когда вы переходите к другому полю, JavaScript проверяет, правильно ли заполнено предыдущее. Если есть ошибка, появляется подсказка. Например, имя не должно содержать цифры, возраст не может быть больше 99, а ссылку на GitHub нужно указывать вместе с датой регистрации.

После нажатия «Отправить анкету» проверяются все поля. Если всё правильно, окно закрывается, а на странице появляется карточка с введёнными данными. Телефон показывается в формате `+7 (999) 123-4567`. Сам пароль в карточку не вывожу.

Для оформления подключила библиотеку Pico CSS и добавила собственные стили. Для проверки полей использовала Constraint Validation API и события JavaScript.

## Файлы

- `index.html` — страница и форма регистрации.
- `style.css` — оформление страницы и окна.
- `script.js` — проверки полей, кнопки и создание карточки.
- `eslint.config.mjs` и `package.json` — настройки проверки JavaScript.

## Как запустить на MacBook

Если репозиторий ещё не скачан:

```bash
git clone https://github.com/alinakashafutdinova/client-side-basics.git
cd client-side-basics
git switch lab3
```

Откройте Терминал в папке проекта и выполните:

```bash
python3 -m http.server 8000
```

Откройте в браузере `http://localhost:8000`. Чтобы остановить сервер, нажмите `Ctrl + C` в Терминале.

## Как запустить на Windows

Скачайте проект или клонируйте его через Git, затем перейдите в ветку `lab3`. Откройте PowerShell в папке проекта и выполните:

```powershell
py -m http.server 8000
```

Откройте `http://localhost:8000` в браузере. Команда работает, если установлен Python. Если Python не установлен, откройте `index.html` прямо в браузере или используйте Live Server в VS Code.

Для загрузки Pico CSS нужен интернет. Если он недоступен, основные стили в `style.css` всё равно будут работать.

## Как проверить работу формы

1. Откройте окно регистрации и нажмите «Отправить анкету» с пустыми полями. Должны появиться ошибки у имени и почты, а курсор перейдёт к первому полю.
2. Введите в имя цифры, неправильную почту, короткий телефон или возраст больше 99. После выхода из поля появится сообщение об ошибке.
3. Попробуйте указать только ссылку на GitHub без даты, а потом только дату без ссылки.
4. Введите пароль короче 6 символов. Удерживайте кнопку показа пароля — пароль должен отображаться, пока вы удерживаете кнопку.
5. Исправьте ошибки и отправьте форму. Должна появиться карточка. Проверьте формат телефона.
6. Откройте форму ещё раз и закройте её кнопкой, клавишей `Esc` и нажатием на затемнённый фон.
7. Проверьте консоль браузера: на MacBook `⌘ Command + ⌥ Option + J`, на Windows `Ctrl + Shift + J`.

Данные никуда не отправляются и после обновления страницы сбрасываются — это учебная форма.
