## Что я сделала

В этой работе сделала три примера утечек памяти. В каждом можно создать 80 карточек, удалить их со страницы и проверить, почему браузер всё равно продолжает хранить эти элементы.

1. **Обработчики событий.** Для карточек создаются обработчики `resize` на `window`. После удаления карточек они продолжают работать.
2. **Глобальный Map.** Карточки добавляются в коллекцию, а после удаления из DOM остаются в ней.
3. **Таймеры.** Для карточек создаются интервалы, которые продолжают хранить ссылки на удалённые элементы.

У каждого примера есть три кнопки: создание, удаление из DOM и устранение утечки. После исправления можно проверить, что удерживающие ссылки исчезли. Счётчики на странице показывают количество карточек и ссылок, **а не размер памяти**.

## Запуск на MacBook

Если репозиторий ещё не скачан:

```bash
git clone https://github.com/alinakashafutdinova/client-side-basics.git
cd client-side-basics
git switch lab8
```

Откройте Терминал в папке лабораторной и запустите простой локальный сервер:

```bash
python3 -m http.server 8000
```

Откройте в браузере `http://localhost:8000`.

## Запуск на Windows

Скачайте архив или клонируйте репозиторий и выберите ветку `lab8`. Откройте PowerShell в папке проекта и выполните:

```powershell
py -m http.server 8000
```

Перейдите в браузере по адресу `http://localhost:8000`. Если Python не установлен, можно открыть проект через расширение **Live Server** в VS Code.

## Как проверить утечки через DevTools

1. Откройте сайт в Chrome или Яндекс Браузере в режиме инкогнито, без расширений.
2. Откройте инструменты разработчика: **MacBook — `⌘ + ⌥ + I`**, **Windows — `F12`** или `Ctrl + Shift + I`.
3. Перейдите на вкладку **Memory (Память)** и выберите **Heap snapshot**.
4. Нажмите кнопку сборки мусора и сделайте первый снимок.
5. Создайте элементы в первом эксперименте и удалите их. Нажмите сборку мусора и сделайте второй снимок.
6. Повторите создание и удаление элементов. Снова вызовите сборку мусора и сделайте третий снимок.
7. Найдите `Detached`-элементы, откройте **Retainers** и посмотрите, кто хранит ссылку на удалённую карточку.
8. Нажмите «Устранить утечку». Повторите снимок и проверьте, что карточки больше не удерживаются.
9. Проведите те же действия для второго и третьего экспериментов. Лучше обновить страницу между сценариями, чтобы сравнение было нагляднее.

Все скриншоты вкладки Memory нужно сохранить в папку `evidence/devtools/`. Названия и список снимков указаны в `REPORT.md`. **Эти скриншоты ещё нужно сделать в DevTools перед сдачей**: в архиве есть измерения через Chrome DevTools Protocol и снимки самой страницы, но не изображения вкладки Memory.
