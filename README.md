## Что я сделала

В этой работе потренировалась писать функции, условия и циклы на JavaScript. Всего сделала 11 заданий: треугольник, Fizz-Buzz, ёлка, деление, сэндвичи, модуль числа, перевод температуры, случайные числа, выбор и фильтрация элементов массива, сравнение дробных чисел.

Код всех заданий находится в `script.js`. В `index.html` сделала страницу с именем и списком заданий, а в `style.css` — оформление. Результаты выводятся в консоль браузера.

## Как запустить на MacBook

1. Скачайте проект и откройте папку с лабораторной.
2. Если скачиваете проект через Git, выполните:

```bash
git clone https://github.com/alinakashafutdinova/client-side-basics.git
cd client-side-basics
git switch lab1
```

3. Чтобы запустить локальный сервер, откройте Терминал в папке проекта и введите:

```bash
python3 -m http.server 8000
```

4. Откройте в браузере `http://localhost:8000`.
5. В Chrome или Яндекс Браузере откройте консоль сочетанием `⌘ Command + ⌥ Option + J`.

## Как запустить на Windows

1. Скачайте проект (или клонируйте его через Git и перейдите на ветку `lab1`).
2. Откройте PowerShell в папке с файлами.
3. Если у вас установлен Python, выполните:

```powershell
py -m http.server 8000
```

4. Откройте `http://localhost:8000` в браузере.
5. Откройте консоль сочетанием `Ctrl + Shift + J`.

Если Python не установлен, можете просто открыть `index.html` двойным щелчком. Но локальный сервер удобнее: при открытии через `file://` браузер иногда показывает предупреждения безопасности, не связанные с заданиями.
