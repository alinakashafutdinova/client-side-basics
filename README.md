**Дисциплина:** Основы веб-разработки на стороне клиента  
**Студентка:** Кашафутдинова Алина Тимуровна  
**Группа:** 257-321

## Цель

Научиться получать элементы DOM, менять их содержимое и свойства, создавать новые узлы, обрабатывать события пользователя и управлять состоянием интерфейса.

## Выполненные задания

1. **Like:** кнопка-переключатель с доступным состоянием `aria-pressed`.
2. **Like / Dislike:** взаимно исключающие реакции, повторное нажатие снимает выбор.
3. **Корзина:** три карточки с фотографией и описанием; счётчик товаров в правом верхнем углу значка корзины. При каждом нажатии число увеличивается на один.
4. **Сортировка:** массив из 12 случайных чисел, три кнопки (возрастание, убывание, исходный порядок). Список элементов `ul/li` создаётся через `createElement`, без `innerHTML`.
5. **Галерея:** 10 фотографий, выбор удержанием на 1 секунду, нумерация в месте нажатия, дальнейший выбор обычными нажатиями, снятие выбора, перенос в раздел «Скопированные» или удаление. Порядок переноса совпадает с порядком выбора.

## Структура проекта

- `index.html` — разметка пяти заданий.
- `style.css` — стили для компьютера и телефона.
- `script.js` — обработчики событий и работа с DOM.
- `eslint.config.mjs` — правила проверки JavaScript по требованиям задания.
- `package.json` — настройки проекта и команды ESLint.
- `.gitignore` — исключения для Git.

## Запуск на MacBook

Сайт не требует сервера и библиотек для своей основной работы. Для удобства можно открыть его через локальный сервер:

```bash
python3 -m http.server 8000
```

Затем в браузере открыть `http://localhost:8000`.

Фотографии для учебного примера загружаются с `images.unsplash.com`, поэтому для их отображения нужен интернет.

## Проверка ESLint

Для первой настройки используется Node.js чётной версии. В папке проекта:

```bash
npm install
npm run lint
```

При успешной проверке ESLint завершается без вывода ошибок. Папка `node_modules` не добавляется в Git.

## Проверка работы в браузере

1. Нажать «Нравится» дважды: состояние должно включиться и выключиться.
2. В блоке Like / Dislike выбрать сначала одну, потом вторую реакцию: одновременно обе активными быть не должны.
3. Добавить несколько товаров: число в значке корзины увеличивается на каждое нажатие.
4. Отсортировать числа тремя способами: исходный порядок должен восстановиться точно.
5. В галерее зажать фото на секунду, затем выбрать ещё два обычными кликами. Отменить выбор одного фото и проверить перенумерацию. Перенести выбранные фотографии и проверить порядок в разделе «Скопированные». Для других фото проверить удаление.
6. Открыть консоль браузера и убедиться, что JavaScript работает без ошибок.

**Выбор с клавиатуры:** на кнопке фотографии нажать `Shift+Enter`, далее `Enter` для выбора/отмены остальных фотографий.
