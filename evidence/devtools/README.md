# Скриншоты памяти из DevTools

Сюда нужно положить скриншоты из вкладки Memory после выполнения всех трёх экспериментов.

Сценарии: `events`, `cache`, `timers`.

Для каждого сохраните четыре скриншота с именами:

- `<сценарий>-1.png` — базовый снимок памяти.
- `<сценарий>-2.png` — после первого создания и удаления карточек.
- `<сценарий>-3.png` — после второго создания и удаления карточек.
- `<сценарий>-retainers.png` — найденный Detached-элемент и панель Retainers.

Изображения нужны для полного соответствия требованию преподавателя о скриншотах. Графики в соседней папке составлены по результатам профилирования через Chrome DevTools Protocol и не подменяют снимки из интерфейса DevTools.
