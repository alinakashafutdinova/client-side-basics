02 / Методика

Какие методы сравниваются

Добавление элементов

  1. appendChild() — по одному узлу
  2. DocumentFragment — через фрагмент
  3. innerHTML — вставка HTML-строки
  4. insertAdjacentHTML() — вставка HTML в конец

Удаление элементов

  1. removeChild() — в цикле
  2. innerHTML = '' — очистка строки
  3. replaceChildren() — замена содержимого
  4. Range.deleteContents() — удаление диапазона

04 / Важно знать

Как читать результаты

Чем меньше среднее время, тем быстрее выполнялся метод в данном эксперименте. Стандартное отклонение показывает разброс замеров. Доверительный интервал помогает оценить точность среднего.

По упрощённому правилу из задания, если 95% интервалы не пересекаются, различие считают статистически значимым. Это не заменяет полноценный статистический тест.

Для сравнения на разных компьютерах повторите эксперимент отдельно: версия браузера, нагрузка системы и характеристики устройства влияют на измерения.
